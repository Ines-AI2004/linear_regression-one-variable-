# Simple Linear Regression With One Variable from Scratch

This project implements **Simple Linear Regression** from scratch using **NumPy** and **Python** to analyze and predict salary trends in the AI industry based on years of experience.

---

## 📌 Project Overview
The goal of this project is to build a machine learning regression model from the ground up without using high-level ML libraries like Scikit-Learn. 

- **Model Equation:** $f_{w,b}(x) = w \cdot x + b$
- **Dataset:** Global AI Job Market & Salary Trends
- **Primary Feature ($x$):** Years of Experience
- **Target Variable ($y$):** Salary in USD

---

## 📊 Dataset
The dataset used in this project contains salary and background information for AI professionals.
- **Size:** 15000 rows × 8 columns
- **Selected Feature:** `Years of Experience`
- **Selected Target:** `Salary (in USD)`

---

## 🛠️ Tools & Technologies Used
* **Python**
* **NumPy:** For linear algebra and vectorized matrix calculations.
* **Pandas:** For data loading and preprocessing.
* **Matplotlib:** For data visualization and plotting the regression line.
* **Google Colab:** Environment used for code execution and analysis.
